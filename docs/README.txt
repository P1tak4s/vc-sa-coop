VC / SA Co-op
=============

Unofficial co-op mod for GTA Vice City and San Andreas Definitive Edition (Steam).
Not a Rockstar Games or Take-Two product.

Install
1. Unzip this folder anywhere (for example, on your desktop).
2. Close the game and run VC-SA-Coop.exe.
3. Click INSTALL, then PLAY.

Playing together
- In the game: ESC, then CO-OP. Pick a session name and a password.
- Your friend enters the same name and password.
- G: get into your friend's car. E: revive your friend. F: get out.

Uninstall
Run VC-SA-Coop.exe and click "Uninstall".

What the program does
It copies files into the game folder and writes graphics lines to Documents\Rockstar Games.
No admin rights needed. Open source: https://github.com/P1tak4s/vc-sa-coop

Windows may show "Windows protected your PC": the program is unsigned (a certificate costs money).
Click "More info", then "Run anyway". If in doubt, read the code on GitHub.

Third-party tools (licenses in the extra and game folders): CLEO Redux, Ultimate ASI Loader, repak,
UAssetAPI (MenuPatch), ReShade.
